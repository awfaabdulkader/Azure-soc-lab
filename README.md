# Solo SOC Lab

## Overview

A cloud-based Security Operations Center (SOC) built on Microsoft Azure.

This project demonstrates the deployment of a complete monitoring environment capable of collecting, analyzing, and visualizing security events from Linux and Windows systems.

## Technologies

- Microsoft Azure
- Ubuntu Server 24.04 LTS
- Wazuh
- Suricata IDS
- Elasticsearch
- Kibana
- Logstash
- ElastAlert
- DVWA
- Apache
- MySQL
- VMware Workstation
- Windows 10
- Git

## Architecture

- Azure Virtual Network
- DMZ subnet
- Monitoring subnet
- Honeypot server
- SOC server
- Windows log collector
